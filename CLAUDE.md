# Hard rules
1. Expo SDK 57 only. Never upgrade Expo or React Native. Never install SDK 58 or run `expo install --fix` without asking the user.
2. Install packages with `npx expo install <pkg>`, never `npm install`, so versions match SDK 57.
3. Never run `npx expo start`. The user runs it in a separate terminal so they can see the QR code.
4. The app must run in Expo Go: no prebuild, no development builds, no native modules outside Expo Go.
5. Do not use react-native-purchases-ui (its paywall is a placeholder in Expo Go). We build our own paywall screen.
6. Never commit secrets. The RevenueCat `test_` key is a public SDK key and may live in code. Gemini keys and Worker secrets never enter the repo.
7. Use code the user pastes VERBATIM for the named files. You may fix TypeScript errors, but do not change the 3Dmol.js or react-native-purchases calls; they are verified against current docs.
8. Commit after each step with a clear message. Do not push until the user gives the GitHub URL.

# MoleculeLens Rx — project context
One line: search or scan a medicine → see it sitting inside the protein it acts on, in interactive 3D, with plain-language cards, plus warnings when two medicines in your cabinet hit the same protein. Entry for RevenueCat Shipaton 2026, Next Gen (student) category. Deadline Wed Sep 30 2026; we submit by 9 pm ET.

Stack (verified Sep 25 2026): Expo SDK 57 (React Native 0.86), TypeScript, Expo Router, Expo Go on an iPhone 16 Pro (Expo Go requires login on CLI and app). react-native-webview 13.16.1 + 3Dmol.js 2.5.5 (CDN https://cdnjs.cloudflare.com/ajax/libs/3Dmol/2.5.5/3Dmol-min.js). react-native-purchases 10.10.x with RevenueCat Test Store: a `test_` key works in Expo Go; purchasePackage shows a "Test Store Purchase" alert with "Test valid purchase"; addCustomerInfoUpdateListener never fires in Expo Go, so always re-fetch getCustomerInfo() after a purchase; purchaseProduct is unsupported there, use purchasePackage. expo-camera CameraView for barcodes (barcodeTypes upc_a, upc_e, ean13). @react-native-async-storage/async-storage for local storage. Cloudflare Worker (worker/) calling gemini-3.8-flash; key stays in Worker secrets.

Data (all free, no keys): bundled hero list src/data/heroList.json generated by scripts/build-hero-list.mjs from ChEMBL mechanism API → ChEMBL target → target_components[].accession → UniProt REST; RCSB PDB drug-bound structures (https://files.rcsb.org/download/<ID>.pdb); AlphaFold DB v6 fallback (https://alphafold.ebi.ac.uk/files/AF-<ACC>-F1-model_v6.pdb); RxNorm (rxnav.nlm.nih.gov/REST, 20 req/s) for names and as the barcode fallback (package NDC → rxcui.json?idtype=NDC → rxcui/<id>/related.json?tty=IN); required attribution: "This product uses publicly available data from the U.S. National Library of Medicine (NLM), National Institutes of Health, Department of Health and Human Services; NLM is not responsible for the product and does not endorse or recommend this or any other product."; openFDA drug/ndc.json and drug/label.json for NDC/UPC (openFDA stores UPCs zero-padded to 13 digits; no-key limit 1,000/day).
Verified IDs: ibuprofen = CHEMBL521 → mechanism target CHEMBL2094253 ("Cyclooxygenase", a protein FAMILY; expand target_components) → UniProt P35354 (COX-2, gene PTGS2) and P23219 (COX-1, gene PTGS1), human. PDB 4PH9 = ibuprofen bound to MOUSE COX-2, ligand code IBP, dimer → show chain A only. Atorvastatin = CHEMBL1487, PDB 1HWK (human HMG-CoA reductase), ligand code 117. Aspirin = CHEMBL25. RxNorm ibuprofen rxcui 5640. US drug UPC starting with 3: digits 2–11 are the 10-digit NDC; try 4-4-2, 5-3-2 and 5-4-1 against openFDA.

RevenueCat: Test Store products lens_pro_monthly (subscription, 1 month, $4.99), lens_pro_yearly (subscription, 1 year, $29.99), study_pack (non-consumable, $9.99). Entitlements: pro (both subs), study (study_pack). Offering "default" marked Current with packages Monthly / Annual / Lifetime. Free tier: unlimited lookups, the 3D view, basic cards, EVERY shared-target warning (safety is never paywalled), cabinet up to 3 medicines. Lens Pro: unlimited cabinet, side-effect and metabolism deep dives, exportable "how my medicines work" sheet. Study Pack: flashcards + quizzes.

Safety and honesty rules for all UI copy: educational only; never give doses; "Ask your pharmacist" on every warning; say when a structure comes from an animal protein (4PH9 is mouse COX-2); show "mechanism still debated" for acetaminophen instead of forcing a protein. The AI never chooses the protein; it only explains verified facts.

# Cloudflare Worker (worker/)
- NOT DEPLOYED for the Sep 30 2026 submission (the Gemini key needs an 18+ Google account). Keep worker/ in the repo as built; the app runs without EXPO_PUBLIC_WORKER_URL.
- worker/src/index.js, name moleculelens-explain. Plain npm project (no scaffolder); `npm run dev` = wrangler dev, `npm run deploy` = wrangler deploy. Run npm inside worker/.
- Endpoints: GET /health → { ok: true }. POST /explain → { protein, drug, effect }; POST /deepdive → { sideEffects, metabolism }. Both need header x-app-token == APP_TOKEN (else 401). Body: { drug, protein, shortName, gene, uniprotId, functionText, mechanism, actionType, structureNote? }.
- Calls gemini-3.8-flash generateContent (x-goog-api-key, responseMimeType application/json, temperature 0.3). Gemini non-2xx → 502 { error: "gemini <status>" }; wrong JSON shape → 502. Success adds Cache-Control: private, max-age=86400.
- Secrets: GEMINI_API_KEY and APP_TOKEN live ONLY in Worker secrets (`npx wrangler secret put`); locally in worker/.dev.vars (git-ignored; template worker/.dev.vars.example). GEMINI_API_KEY never enters the app or the repo.
- APP_TOKEN is abuse deterrence, not security: the app ships it as EXPO_PUBLIC_APP_TOKEN, so anyone can extract it from the bundle.
- App config in .env: EXPO_PUBLIC_WORKER_URL (the workers.dev URL, no trailing slash) and EXPO_PUBLIC_APP_TOKEN. The user and their parent run wrangler login / secret put / deploy — Claude never does.
